# Дашборд продаж

Показывает цифры из Google-таблицы графиками на одной странице.

## Как обновить данные

Поменяйте цифры в таблице. Страница обновится сама в течение часа.

Нужно сразу — вкладка **Actions** в этом репозитории → **refresh** →
**Run workflow**. Через минуту готово.

## Формат таблицы

Первая строка — заголовки, ровно такие:

| Месяц | Заказы | Выручка |
|---|---|---|
| Январь | 120 | 340000 |
| Февраль | 145 | 398000 |

Выручка — целое число без пробелов и знака валюты.

Если в данных что-то не так — пустая ячейка, текст вместо числа, повтор месяца,
подозрительно большое значение — страница покажет это блоком сверху. Цифры при
этом остаются как есть: код ничего не исправляет сам.

## Как устроено

```
Google-таблица → data.py → build.py → index.html → Vercel
```

Страница собирается заранее и раздаётся готовым файлом. В таблицу ходит сборка,
а не браузер посетителя — поэтому ключ не попадает к посетителям.

| Файл | Что делает |
|---|---|
| `data.py` | читает таблицу, проверяет данные |
| `build.py` | считает итоги, рисует страницу |
| `index.html` | результат, его раздаёт Vercel |
| `.github/workflows/refresh.yml` | пересборка раз в час |

## Запуск у себя

```bash
cp .env.example .env      # вписать свой ключ и id таблицы
python3 build.py
open index.html
```

Без `.env` скрипт работает на выдуманных данных — это нормально и безопасно.

## Ключи

`GOOGLE_API_KEY` и `SHEET_ID` берутся только из окружения: локально из `.env`,
на GitHub из секретов Actions. В коде их нет и быть не должно.
