# dashboard

Дашборд продаж. Данные берутся из Google-таблицы, страница собирается скриптом.

## Как устроено

```
Google-таблица  →  data.py  →  build.py  →  index.html
```

- `data.py` — достаёт строки. Три источника, в порядке приоритета:
  API по ключу → открытая таблица по ссылке (CSV) → выдуманные данные.
- `build.py` — считает итоги и рисует страницу.
- `index.html` — результат. Его и раздаёт Vercel.

## Пересобрать

```bash
python3 build.py
```

## Ключи

`GOOGLE_API_KEY` берётся только из переменной окружения. В код его не вписывать:
репозиторий публичный.
